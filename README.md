## index.html の更新手順

このファイルは自動生成されたもので、原本はこのリポジトリには無い。

1. 別途管理している経歴データ（`career.yaml`）と本文（`content.yaml`）を編集する
2. `python3 build.py` を実行して `build/site/index.html` を生成する
3. 生成された `index.html` をこのリポジトリのルートにコピーしてコミットする

同じ原本から PDF 版（ポートフォリオ / スキルシート）も出力している。
文言や経歴を直すときは必ず原本側を直すこと。ここを直しても次のビルドで消える。

## 独自ドメイン

`devopsworker.jp` を割り当てる。DNS（お名前.com）に GitHub Pages の A レコードを
設定したうえで、リポジトリ設定の Pages > Custom domain に登録する。
順序を逆にすると github.io からのリダイレクト先が解決できず、サイトが見られなくなる。
